Vault Radio - Korean Modified Version


# 이 프로젝트에 대해

이 플러그인은 Laevin님의 Vault Radio를 기반으로 한국 사용자를 위해 수정한 버전입니다. 

훌륭한 오픈소스 플러그인을 제공해주신 원작자님께 감사드립니다.

## 수정 사항

✅ 한국어 UI 번역 - 인터페이스 메시지 한글화

✅ 헤더 아이콘 위치 조정 - 더 나은 레이아웃

✅ 볼륨 조절 기능 추가 - 세밀한 볼륨 컨트롤

## 설치 방법

Releases 페이지에서 최신 버전 다운로드
Obsidian 볼트의 .obsidian/plugins/vault-radio/ 폴더 생성
다운받은 파일들을 해당 폴더에 복사
Obsidian 재시작 후 설정 > 커뮤니티 플러그인에서 활성화

## 지원 형식
FLAC, MP3, WAV, M4A, OGG 등 Obsidian이 지원하는 모든 오디오 형식

## 주요 기능

상태바 음악 재생
여러 폴더 관리
즐겨찾기 목록
드래그 앤 드롭으로 문서 삽입
